# Keyboard shortcuts

Shortcuts are ignored while you type in a text field.

## Tools

| Action | Keys |
| --- | --- |
| Pen | ++1++ or ++p++ |
| Eraser | ++2++ or ++e++ |
| Lasso | ++3++ or ++shift+l++ |
| Lasso eraser | ++4++ or ++ctrl+shift+e++ |
| Line | ++l++ |
| Pan | ++g++ |
| Path (Bézier) | ++b++ |
| Node (edit points) | ++n++ |
| Select (move/duplicate paths) | ++s++ |
| Vectorize (trace an outline) | ++v++ |
| Skeletonize (trace a centreline) | ++k++ |

Hold the middle mouse button to pan from any tool.

## Editing

| Action | Keys |
| --- | --- |
| Undo | ++ctrl+z++ |
| Redo | ++ctrl+y++ |

Raster and vector edits share one history, so ++ctrl+z++ undoes your last action
of either kind. An action that touches both, such as rasterising a shape, is
undone in one step.

## View

| Action | Keys |
| --- | --- |
| Toggle visibility of all labels | ++tab++ |
| Next label | ++ctrl+tab++ |
| Previous label | ++ctrl+shift+tab++ |
| Toggle edge display | ++ctrl+e++ |
| Toggle image processing | ++q++ |
| Toggle post-processing | ++d++ |
| Zoom in | ++equal++ or ++plus++ |
| Zoom out | ++minus++ |

## Navigation

| Action | Keys |
| --- | --- |
| Next sequence | ++arrow-right++ |
| Previous sequence | ++arrow-left++ |
| Next frame in sequence | ++arrow-up++ |
| Previous frame in sequence | ++arrow-down++ |

## File

| Action | Keys |
| --- | --- |
| Save annotations | ++ctrl+s++ |

Annotations are also saved automatically a few seconds after you stop editing,
and before you leave a frame.
