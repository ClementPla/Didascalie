# Keyboard shortcuts

These work in the editor. They are ignored while you type in a text field.

## Tools

| Tool | Keys |
| --- | --- |
| Pen | ++p++ or ++1++ |
| Eraser | ++e++ or ++2++ |
| Lasso | ++shift+l++ or ++3++ |
| Lasso eraser | ++ctrl+shift+e++ or ++4++ |
| Line | ++l++ |
| Draw shape | ++b++ |
| Edit points | ++n++ |
| Select | ++s++ |
| Trace outline | ++v++ |
| Trace centerline | ++k++ |
| Pan | ++g++ |

Hold ++alt++ to open the quick-access wheel at the pointer and pick a tool from
it.

## Moving around

| Action | Keys |
| --- | --- |
| Pan | Hold ++space++, or drag with the middle mouse button |
| Zoom in | ++plus++ or ++equal++ |
| Zoom out | ++minus++ |
| Next frame | ++arrow-up++ |
| Previous frame | ++arrow-down++ |
| Next sequence | ++arrow-right++ |
| Previous sequence | ++arrow-left++ |

## Labels and display

| Action | Keys |
| --- | --- |
| Next label | ++ctrl+tab++ |
| Previous label | ++ctrl+shift+tab++ |
| Hide or show all labels | ++tab++ |
| Show masks as outlines | ++ctrl+e++ |
| Brush size | ++ctrl++ + wheel |
| Image adjustments on or off | ++q++ |
| Auto-segment the stroke on or off | ++d++ |

## Editing and saving

| Action | Keys |
| --- | --- |
| Undo | ++ctrl+z++ |
| Redo | ++ctrl+y++ |
| Save and mark the frame reviewed | ++ctrl+s++ |

Mask and shape edits share one undo history.

Annotations are also saved automatically a few seconds after you stop editing,
and when you leave a frame.
